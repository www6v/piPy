**Goal:** 在 P1/P2 之上补齐 pi 官方 [Start here](https://pi.dev/docs/latest) 中影响「长会话 + 项目感知 + 并发交互 + 生产可靠性」的四项核心能力：**Compaction**、**Context files**、**steer/follow_up 消息队列**、**Auto-retry**。

**Tech Stack:** Python 3.11+、`uv` workspace、`httpx`、`jsonschema`、`pytest`、`ruff`（与既有包相同）

## 1. P3a 功能地图

| 顺序 | 能力 | pi 对标 | piPy 目标 |
|------|------|---------|-----------|
| **P3a-1** | Compaction | `compaction/compaction.ts`、`/compact` | 手动 + 自动阈值压缩；JSONL `compaction` 条目 |
| **P3a-2** | Context files | `resource-loader.ts`、`system-prompt.ts` | `AGENTS.md`/`CLAUDE.md`、`.pi/SYSTEM.md` |
| **P3a-3** | Message queue | `agent.ts` steering/followUp、`agent-loop.ts` | `steer()`/`follow_up()` + `queue_update` 事件 |
| **P3a-4** | Auto-retry | `agent-session.ts` `_isRetryableError` | 529/rate limit/5xx 指数退避重试 |

**本计划范围：** P3a-1 → P3a-4 + 文档。**明确不做：** Session 树/fork（P3b）、Extensions/Skills、OAuth `/login`、TUI。

## 2. P3a 成功标准（可演示）

```bash
uv sync && uv run pytest

# P3a-2: Context files 注入 system prompt
echo "# Use pytest for tests" > AGENTS.md
./pipy-test.sh -p "What testing framework?" --provider faux --model faux/test -v
# stderr/assistant 应能引用 AGENTS.md 内容（faux 可断言 system prompt 含 project_context）

# P3a-1: 手动 compaction（faux 或集成测试）
./pipy-test.sh -c -p "..."   # 长会话后
# REPL: /compact
# RPC: echo '{"type":"compact"}' | pipy --mode rpc ...

# P3a-3: streaming 时 steer
# RPC: prompt 运行中发送 {"type":"steer","message":"stop and summarize"}
# 或 REPL 在 tool 执行期间输入第二条消息（steering 语义）

# P3a-4: faux 模拟 retryable error → auto_retry_start/end 事件
./pipy-test.sh --mode json -p "trigger retry" --provider faux --model faux/retry-test
```

验收：

1. **Compaction：** 超阈值触发 `compaction_start`/`compaction_end`；session JSONL 含 `type: compaction` 条目；reload 后 LLM 上下文 = summary + 保留的 recent messages。
2. **Context files：** 从 `~/.pi/agent/` 与 cwd 向上加载；`--no-context-files` 禁用；与 pi 相同的 `<project_context>` XML 包裹。
3. **Queue：** streaming 时 `prompt` + `streamingBehavior: steer|followUp` 成功；独立 `steer`/`follow_up` RPC 命令；`get_state.pendingMessageCount` 正确。
4. **Retry：** 可配置 `settings.json` `retry.enabled`；retryable 错误自动重试；context overflow **不**重试（留给 compaction）。
5. 全量 `uv run pytest` 通过；CI 仍不依赖真实 API。

## 4. 设计决策

| 决策 | 理由 |
|------|------|
| Compaction 先 **线性 session**（无 branch tree） | 与当前 `SessionManager` 一致；`firstKeptEntryId` 用 entry `id` 字段 |
| 压缩摘要用 **同 session 的 model** + `complete_simple` | 对标 pi；faux provider 注册 `faux/compactor` 供测试 |
| Context files **不**加载 Skills/Prompts | P3b 范围；仅 AGENTS/CLAUDE + SYSTEM/APPEND |
| 消息队列在 **`pi_agent.Agent`** | agent-loop 需在 tool batch 后注入 steering；避免仅在 RPC 层 hack |
| Auto-retry 在 **`AgentSession`** 不在 agent-loop | 对标 pi：session 层 `_handlePostAgentRun` + 删最后 error assistant |
| 默认 `steeringMode`/`followUpMode` = `"one-at-a-time"` | 与 pi settings 默认一致 |
| Compaction 默认 `enabled: true`，`reserveTokens: 16384`，`keepRecentTokens: 20000` | 与 pi `settings-manager.ts` 默认一致 |
